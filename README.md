Part of the [Pipeworx](https://pipeworx.io) open MCP gateway.

|------|-------------|

## Quick Start

Add to your MCP client config:

```json
{
  "mcpServers": {
    "treasury-fiscal": {
      "url": "https://gateway.pipeworx.io/treasury-fiscal/mcp"
    }
  }
}
```

Or use the CLI:

```bash
npx pipeworx use treasury-fiscal
```
